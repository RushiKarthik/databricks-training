# Day 1 - SQL Practice (65 Queries)

Objective

To practice and understand fundamental SQL concepts by solving 65 queries using the Employee and Department tables.

---

##  Topics Covered

###  Basic Queries

* SELECT statements
* Filtering using WHERE clause
* Column selection

###  String Matching

* LIKE operator
* Pattern matching (`%`, `_`)
* Character-based filtering

### Date Functions

* YEAR(), MONTH()
* Date filtering
* Relative date queries

###  Aggregate Functions

* SUM(), AVG(), MIN(), MAX()
* COUNT()

###  GROUP BY & HAVING

* Grouping data
* Filtering grouped results

###  ORDER BY

* Sorting data (ASC, DESC)
* Multi-column sorting


---

##  Tools Used

* DB Fiddle (for executing SQL queries)
* GitHub (for version control and submission)
